# Swatch

Exibe uma amostra de cor com nome e caminho do token.

## When to use

- Documentar tokens de cor no Storybook / workshop
- Comparar tokens semânticos lado a lado

## When NOT to use

- Como indicador de status na UI do produto → use badge/chip dedicado
- Para aplicar cor em componentes → consuma `theme.colors.*` diretamente
