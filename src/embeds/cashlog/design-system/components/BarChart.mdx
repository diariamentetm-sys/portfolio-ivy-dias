# BarChart

Barras **verticais agrupadas** — Real (magenta) × Total aprovado (amarelo), como no dashboard.

## When to use

- Comparar Real × Aprovado por mês

## When NOT to use

- Série temporal contínua → use `LineChart`
- Distribuição por categoria % → use `DonutChart`
