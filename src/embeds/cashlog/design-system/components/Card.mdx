# Card

Painel flat do dashboard Cashlog — superfície branca, borda fina, **sem sombra**.

## When to use

- Agrupar gráfico ou lista em painel (Dispêndio, Real × Aprovado, demandas)
- Blocos laterais do dashboard

## When NOT to use

- KPI pastel do topo → use `MetricCard`
- Elevação / sombra → não faz parte da linguagem visual do Cashlog
