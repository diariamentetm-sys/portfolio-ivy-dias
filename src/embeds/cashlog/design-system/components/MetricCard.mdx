# MetricCard

KPI flat do dashboard — fill pastel (`lilac` / `yellow`), valor grande, trend e sparkline. Sem borda e sem sombra.

## When to use

- Fila de status no topo (Em aprovação, Para concluir, Em holding, Aprovadas)

## When NOT to use

- Painel com gráfico → use `Card` + `LineChart` / `BarChart` / `DonutChart`
