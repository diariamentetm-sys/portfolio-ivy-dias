# Button

Dispara uma ação com variantes de ênfase visual.

## When to use

- Confirmar ou enviar uma ação principal (`primary`)
- Ação secundária no mesmo contexto (`secondary`)
- Ação de baixa ênfase / terciária (`ghost`)

## When NOT to use

- Navegação entre páginas → use `<a href>` / link
- Toggle on/off persistente → use um control dedicado (ainda não no DS)
- Mais de uma `primary` na mesma viewport
