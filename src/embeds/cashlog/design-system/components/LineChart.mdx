# LineChart

Dupla linha do dashboard — **Plano** (pontilhado escuro) × **Real Acumulado** (magenta sólido), com tooltip no ponto ativo.

## When to use

- Dispêndio × Plano Mensal

## When NOT to use

- Comparação categórica mensal com duas séries discretas → `BarChart`
