# Gráficos

Linguagem visual do dashboard Cashlog: **flat**, séries magenta/amarelo/cinza — não barras horizontais genéricas nem sombras em cards.

## Tokens de série (`theme.colors.chart`)

| Série | Token |
|---|---|
| Real / Real acumulado | `chart.real` |
| Plano | `chart.plan` |
| Total aprovado | `chart.approved` |
| Donut A–D | `chart.segmentA` … `segmentD` |
| Grid | `chart.grid` |

<div style={{ display: "flex", gap: theme.spacing[3], flexWrap: "wrap", marginTop: theme.spacing[4] }}>
  {[
    ["real", theme.colors.chart.real],
    ["plan", theme.colors.chart.plan],
    ["approved", theme.colors.chart.approved],
    ["segmentA", theme.colors.chart.segmentA],
    ["segmentB", theme.colors.chart.segmentB],
    ["segmentC", theme.colors.chart.segmentC],
    ["segmentD", theme.colors.chart.segmentD],
  ].map(([label, color]) => (
    <div key={label} style={{ width: 96 }}>
      <div style={{ height: 48, backgroundColor: color, borderRadius: theme.radius.md }} aria-hidden />
      <p style={{ fontSize: theme.fontSize.xs, color: theme.colors.text.muted, marginTop: theme.spacing[2] }}>{label}</p>
    </div>
  ))}
</div>
