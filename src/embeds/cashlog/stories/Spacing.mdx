# Espaçamento, radius e sombra

Tokens de layout — não são componentes. Use via `theme.spacing`, `theme.radius`, `theme.shadow`.

## Spacing

<div style={{ display: "flex", flexDirection: "column", gap: theme.spacing[4], marginTop: theme.spacing[4] }}>
  {[1, 2, 3, 4, 5, 6, 8, 10, 12].map((key) => (
    <div key={key} style={{ display: "flex", alignItems: "center", gap: theme.spacing[4] }}>
      <code style={{ width: 160, fontSize: theme.fontSize.xs, color: theme.colors.text.muted }}>
        theme.spacing[{key}] · {theme.spacing[key]}
      </code>
      <div
        style={{
          height: theme.spacing[4],
          width: theme.spacing[key],
          backgroundColor: theme.colors.brand.primary,
          borderRadius: theme.radius.sm,
        }}
        aria-hidden
      />
    </div>
  ))}
</div>

## Radius

<div style={{ display: "flex", flexWrap: "wrap", gap: theme.spacing[4], marginTop: theme.spacing[8] }}>
  {[
    ["sm", theme.radius.sm],
    ["md", theme.radius.md],
    ["lg", theme.radius.lg],
    ["xl", theme.radius.xl],
  ].map(([key, radius]) => (
    <div key={key} style={{ textAlign: "center" }}>
      <div
        style={{
          width: 72,
          height: 72,
          backgroundColor: theme.colors.brand.primarySubtle,
          border: `2px solid ${theme.colors.border.brand}`,
          borderRadius: radius,
        }}
        aria-hidden
      />
      <p style={{ fontSize: theme.fontSize.xs, color: theme.colors.text.muted, marginTop: theme.spacing[2] }}>
        theme.radius.{key}
        <br />
        {radius}
      </p>
    </div>
  ))}
</div>

## Shadow (uso raro)

O dashboard Cashlog é **flat**: cards e KPIs usam `theme.shadow.none`.  
`sm` / `md` ficam para tooltip magenta e FAB — não para painéis.

<div style={{ display: "flex", flexWrap: "wrap", gap: theme.spacing[6], marginTop: theme.spacing[8] }}>
  {[
    ["none", theme.shadow.none],
    ["sm", theme.shadow.sm],
    ["md", theme.shadow.md],
  ].map(([key, shadow]) => (
    <div key={key} style={{ width: 160 }}>
      <div
        style={{
          height: 88,
          borderRadius: theme.radius.md,
          backgroundColor: theme.colors.surface.default,
          border: `1px solid ${theme.colors.border.default}`,
          boxShadow: shadow,
        }}
        aria-hidden
      />
      <p style={{ fontSize: theme.fontSize.xs, color: theme.colors.text.muted, marginTop: theme.spacing[2] }}>
        theme.shadow.{key}
      </p>
    </div>
  ))}
</div>

## Como usar em componentes

```tsx
style={{
  padding: theme.spacing[6],
  borderRadius: theme.radius.md,
  boxShadow: theme.shadow.none,
  border: `1px solid ${theme.colors.border.default}`,
  gap: theme.spacing[3],
}}
```

`Card` e painéis de gráfico já aplicam flat internamente. `MetricCard` usa fills pastel sem borda.
